HTML Validation Evidence — Safiya Nazly

This page documents the W3C HTML validation results for each page I was responsible for: home.html, gallery.html, and content_ST1.html. Each page was validated by direct file upload and all passed with zero errors and zero warnings.

Validator used: W3C Markup Validation Service — https://validator.w3.org/#validate_by_upload

home.html

Result: The home page passed validation with zero errors and zero warnings. The clean result reflects the use of valid semantic HTML5 elements throughout — <header>, <main>, <section>, <nav>, and <footer> — with correct nesting, a single <h1>, and all images carrying descriptive alt attributes.

Reflection on the validation process

All three of my pages — home.html, gallery.html, and content_ST1.html — passed W3C validation with zero errors and zero warnings on the first attempt. This was a result of building with semantic HTML from the start and checking the structure carefully as I wrote it, rather than adding validation as an afterthought. Having a shared global stylesheet also helped, since layout classes were defined once and reused consistently, reducing the chance of structural errors creeping into individual pages.

The page I was most uncertain about before validating was gallery.html, because it contains both an inline <style> block, a large <script> block, and several custom ARIA attributes I had added manually. I was concerned the validator might flag the role="dialog" and aria-modal combination or the tabindex="0" on the non-interactive <div> thumbnail cards. In practice, none of these caused errors — the validator accepted them as valid HTML5 with ARIA extensions, which reinforced my understanding that ARIA attributes are a legitimate part of the HTML specification.

Going through the validation process taught me the value of writing clean, standards-compliant HTML from the outset. Even though all my pages passed first time, reviewing the validator output line by line made me more conscious of choices I had made somewhat automatically — such as ensuring every <img> had an alt attribute, or that section headings followed a logical sequential order. These are habits I will carry forward into future projects.
