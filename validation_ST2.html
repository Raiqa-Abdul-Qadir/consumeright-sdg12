HTML validation evidence — Student 2 — Lakna Dasuni

This page provides evidence of HTML validation for all pages implemented by Student 2 as part of the ConsumeWise website for SDG 12: Responsible Consumption & Production. Each page was validated and corrected until no errors remained.

Validator used: W3C Markup Validation Service — https://validator.w3.org

1. Splash Screen — splash.html

✓ Validated — No Errors

The Splash Screen was validated using the W3C Markup Validation Service (validator.w3.org). The page passed with 0 errors. Minor informational warnings about the <meta http-equiv="refresh"> tag were noted but these do not prevent successful validation.

Reflection on the validation process

During initial validation of ais.html, the validator flagged an error because I had used an aria-pressed attribute on an <article> element with role="button". The validator required the role to be explicitly stated for this to be valid. I added role="button" to each action card element to resolve this.

I used the W3C validator's error messages alongside MDN Web Docs to understand why each error occurred. I then corrected the HTML and re-validated until no errors remained. The iterative process of write → validate → fix → re-validate was very effective.

Validation helped me catch structural mistakes I had missed during development, such as missing alt attributes on validationSnapshots and incorrectly nested heading levels. It reinforced that valid HTML is not just about technical correctness — it directly improves accessibility and ensures cross-browser compatibility. I will validate code during development in future, not just at the end.
