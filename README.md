# ConsumeRight – SDG 12

An accessible, interactive multi-page website about **UN Sustainable Development Goal 12: Responsible Consumption and Production**.

Built in a team of four for the **Web Design and Development** module at IIT Campus.

## Topics Covered

- Food Waste & Loss
- Reducing Plastic Waste & Sustainable Packaging
- Fast Fashion & Clothing Waste
- E-Waste Management

## Pages

- **Splash** – landing page
- **Home** – introduction to SDG 12
- **Content pages** – one in-depth topic page per team member
- **Gallery** – image gallery
- **Feedback** – feedback form and programme directory
- **Team** – team members
- **Profile** – user profile page
- **Sitemap** – overview of all pages
- **Page Editor & Validation** – each member's editor and HTML/CSS validation evidence

## Features

- Responsive layout across desktop and mobile
- Accessibility features following web accessibility guidelines (see `Compliance.pdf`)
- Interactive elements built with JavaScript
- Validated HTML and CSS (screenshots in `validationSnapshots/`)

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/Raiqa-Abdul-Qadir/consumeright-sdg12.git
   ```
2. Open `splash.html` in your browser.

No installation needed.
